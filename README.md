# E-Commerce-Website
E-Commerce Website Clone

Tried simulating a E-Commerce website with a home page, collections page, and a contact Page. 

Home page just have a little animation to inform the offer available in the site. 

The collections page have images of the products available and the each image has a 'Add to Cart' and 'Buy now' Icons.

Contact Page just have a form to fill and the send button have validations of whether there are any fields empty. If not gives an alert the message has been sent.

Technologies Used:
HTML, CSS, Tailwind CSS, Java Script
